# Contributing to True Deal

Thank you for your interest in contribuir para o projeto True Deal!

## Como Contribuir

### Reporting Bugs

Se você encontrou um bug, por favor abra uma issue com:
- Título claro descrevendo o problema
- Passos detalhados para reproduzir
- Screenshots (se aplicável)
- Ambiente (navegador, SO, etc.)

### Sugerindo Features

Abrir uma issue para novas features com:
- Descrição clara da feature
- Casos de uso
- Alternativas consideradas (se houver)

### Pull Requests

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/nova-feature`)
3. Faça commit das mudanças
4. Push para o repositório
5. Abra um Pull Request

### Padrões de Código

- Use TypeScript para todo o código novo
- Siga as convenções do ESLint configurado
- Comente código complexo quando necessário
- Mantenha funções pequenas e focadas

### Commit Messages

Use mensagens de commit descritivas:
- `feat: add new deal creation form`
- `fix: resolve login redirect issue`
- `docs: update README with installation steps`
- `refactor: simplify deal tracking logic`

## Estrutura de Branches

- `main` - Código em produção
- `develop` - Código em desenvolvimento
- `feature/*` - Novas features
- `fix/*` - Correções de bugs
- `hotfix/*` - Correções urgentes

## Perguntas?

Se tiver dúvidas, abra uma issue ou entre em contato através do GitHub.
